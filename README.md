# 화학적 평형 3D 시뮬레이터 (Chemical Equilibrium 3D Simulator)

2NO₂ ⇌ N₂O₄ 등 여러 가역 반응을 3D로 시각화하는 웹 기반 화학 평형 시뮬레이터입니다.
연보랏빛(lavender/purple) 테마의 UI로 제작되었으며, 순수 HTML/CSS/JavaScript + Three.js로
동작하여 별도의 서버나 빌드 과정 없이 브라우저에서 바로 실행됩니다.

## 주요 기능

- **3D 입체 시뮬레이션**: Three.js 기반, 마우스/터치로 자유 회전·확대
- **반응식 선택**: 2NO₂⇌N₂O₄, N₂+3H₂⇌2NH₃(하버법), CO+H₂O⇌CO₂+H₂ 기본 제공
- **커스텀 원소/분자 생성**: 이름, 색상, 화학양론 계수, 반응물/생성물 여부를 직접 지정
- **조건 조절**: 온도(150K~600K), 부피(30%~300%), 각 물질의 입자 수를 슬라이더로 실시간 조정
- **실시간 입자 수 & Q/Kc 표시**: 반응지수와 평형상수를 비교하여 평형 이동 방향을 확인
- **AI 컨트롤 어시스턴트**: 자연어(한국어) 명령을 이해해 컨트롤을 자동 조정, 모호하면 되물어서 대화형으로 진행
- **다운로드/기록**: 화면 PNG 캡처, MP4(webm) 화면 녹화, 그래프 PNG 저장
- **효과음**: 입자 충돌·반응 발생 시 WebAudio 기반 효과음 (외부 파일 불필요)
- **드래그 가능한 실시간 시계**: `YYYY년 MM월 DD일 오전/오후 HH시 MM분 SS초` 형식, 화면 밖으로 나가지 않음
- **문서 분리**: 상단 "평형 원리"/"사용법" 버튼에 화학 이론과 프로그램 사용법이 각각 별도 문서로 제공됨

## 실행 방법

별도 설치 없이 `index.html`을 더블클릭해서 브라우저로 열면 바로 실행됩니다.
(인터넷 연결은 Three.js 및 폰트 로드에만 필요하며, 이후 기능은 오프라인 동작)

로컬 서버로 실행하고 싶다면:
```
npx serve .
```
또는 Python:
```
python -m http.server 8000
```

## GitHub 업로드 (push.bat)

이 저장소는 https://github.com/ramalok3846/chemistry_equalation (public) 을 대상으로 합니다.

1. 이 폴더 전체를 로컬 PC에 다운로드/복사합니다.
2. [Git](https://git-scm.com/download/win)이 설치되어 있어야 하며, GitHub에 로그인되어 있어야 합니다
   (최초 push 시 브라우저 로그인 창 또는 자격증명 관리자 창이 뜰 수 있습니다).
3. `push.bat` 파일을 더블클릭합니다.
4. 커밋 메시지를 입력하라는 창이 뜨면 입력 후 Enter (그냥 Enter만 눌러도 기본 메시지로 커밋됩니다).
5. 자동으로 git init → add → commit → remote 설정 → push 순서로 진행되어 GitHub에 업로드됩니다.

이미 로컬에 git 저장소가 초기화되어 있다면 `push.bat`을 실행할 때마다 변경 사항만 다시 커밋 후 푸시합니다.

## Firebase 구글 로그인에 대하여

요청하신 Firebase 설정(`firebaseConfig`)은 **기본적으로 코드에 포함/활성화하지 않았습니다.**
공개(public) GitHub 저장소에 실제 API 키를 커밋하면 누구나 그 키를 볼 수 있기 때문입니다
(Firebase의 클라이언트 API 키 자체는 보안 규칙으로 보호되도록 설계되어 있지만,
프로젝트 설정을 안전하게 하려면 별도 확인이 필요합니다).
로그인 기능을 실제로 넣고 싶으시면 `docs/firebase-setup.md` 문서를 참고해 직접 연동하시거나,
연동을 도와드릴 수 있으니 말씀해주세요.
